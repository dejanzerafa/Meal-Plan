## Key Rules

- **App is NOT live.** Bio always links to `soulgainz.app/waitlist`. Never say "download now."
- **Hashtag sets** — rotate A/B/C, always include: `#soulgainz #feedyoursoul #fuelyourgainz #soulgainz.app`
- **AI label** — always ON for AI-generated graphics
- **Caption style** — see `instagram-captions.md` for full style guide and approved format
- **Posting times** — feed posts 7:00–7:30am, stories 7:30am + 7:00pm
